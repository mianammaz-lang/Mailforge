# Mailforge Infrastructure Health Dashboard

A complete, production-ready Python application that monitors your Mailforge infrastructure.

## Install

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# or source .venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
```

## Configure

Copy `.env.example` to `.env` and add your API keys.

## Run

```bash
python app.py
```

Then visit `http://localhost:8000`.

## First Scan
After launching the dashboard, navigate to the **API Providers** page to ensure your keys are loaded. 
Click **Run Full Scan** on the dashboard to fetch domains and mailboxes and perform the initial health checks.
